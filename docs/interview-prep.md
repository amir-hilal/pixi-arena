# Interview Prep

- Explain the game loop as a repeated cycle that reads time, updates state, and renders the current frame.
- Describe why update logic and rendering are separated.
- Discuss performance optimization through batching, object reuse, asset management, and avoiding unnecessary allocations.
- Explain architecture decisions around entities as data and systems as behavior.
- Name trade-offs between simple variable timestep updates and more deterministic fixed timestep updates.
- Describe how scenes keep gameplay flow separate from low-level systems.
- Explain how API integration stays isolated from core gameplay logic.
