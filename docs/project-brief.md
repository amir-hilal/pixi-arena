# Project Brief

## Overview

Pixi Arena is a small browser-based 2D game built with TypeScript, Vite, and PixiJS. The project prioritizes clean architecture, fast iteration, and production readiness.

## Scope

- Small browser game with a focused core loop.
- Production-minded structure from the first commit.
- Clear boundaries between rendering, state, systems, and UI.
- Multiplayer-ready architecture with shared simulation and a Socket.IO client transport foundation.
- AI-assisted workflow supported by project rules and review checklists.

## Non-Goals

- No production multiplayer release before the lobby, authoritative server, snapshots, and results flow are implemented.
- No complex physics simulation.
- No custom engine framework.
- No Firebase-backed gameplay transport.

## Tech Stack

- TypeScript
- Vite
- PixiJS
- Socket.IO client
- Browser APIs

## Delivery Goal

Deliver a polished playable prototype with an interview-ready path toward server-authoritative multiplayer.
