# Project Brief

## Overview

Pixi Arena is a small browser-based 2D game built with TypeScript, Vite, and PixiJS. The project prioritizes clean architecture, fast iteration, and production readiness.

## Scope

- Small browser game with a focused core loop.
- Production-minded structure from the first commit.
- Clear boundaries between rendering, state, systems, and UI.
- AI-assisted workflow supported by project rules and review checklists.

## Non-Goals

- No multiplayer.
- No complex physics simulation.
- No custom engine framework.
- No backend implementation inside this repository.

## Tech Stack

- TypeScript
- Vite
- PixiJS
- Browser APIs

## Delivery Goal

Deliver a polished playable prototype within 8 days, with architecture and documentation strong enough to discuss in an engineering interview.
