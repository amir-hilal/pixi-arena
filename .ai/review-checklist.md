# Review Checklist

- [ ] Is logic isolated from rendering?
- [ ] Is performance considered for per-frame work?
- [ ] Is the code readable without hidden control flow?
- [ ] Is state predictable and easy to trace?
- [ ] Are entities kept as data holders?
- [ ] Are systems independent from each other?
- [ ] Are scene responsibilities limited to orchestration?
- [ ] Are constants named instead of embedded as magic numbers?
